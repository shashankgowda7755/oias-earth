Per-tree flat photos: a dual-band-GNSS Android (e.g. Poco X7 Pro ~₹28k, L1+L5 + NavIC) + a GPS-stamp camera app — most accurate point fix, fastest, and it's your 360-controller anyway. Don't crop the sphere for per-tree shots.

⚠️ The honest economics catch. ₹7/tree for 3 years × 100k trees = ₹7 lakh total revenue (~₹2.3 L/yr). Your solo quarterly travel alone is ₹2.45 L/yr — it eats the whole deal. Solo-travel only works if: (a) volume is much higher (≈300k+ trees, so travel/tree → negligible), or (b) semi-annual not quarterly (₹1.23 L/yr), or (c) local crews per city (no travel — you stop flying). At 100k + quarterly + solo, the travel sinks it. This is the real costing decision — not the photo capture.

3 · The auto-tag pipeline — "drop the folder, it tags itself"

GRID
4 corners + spacing → every tree's exact lat/lng + number (cm-accurate)
→
PHOTOS (named)
AA001.jpg → matched to tree AA001 by filename, attached
→
360s (GPS)
each sphere's GPS+heading → hotspots auto-placed for nearby trees
→
RENDER
aerial dots + 360 walk; tap any → tree record
PATH A — per-tree photos

Fully automatic

Drop 10k AA001.jpg… → each links to its tree by filename (our import already keys on tree_unique_id), inherits its grid coordinate. Zero manual. Unmatched names fall into a review list.

PATH B — 360 spheres

Automatic (+1 nudge)

Drop the 360 folder → each sphere's GPS (Theta EXIF) + heading → computeHotspots (bearing→yaw, dist→pitch, 25 m radius, nearest-sphere dedup) auto-places numbered pins. One drag-to-north per sphere only if the heading tag is missing (~10 taps, once).

No AI/CV needed. It's deterministic GPS trigonometry + filename matching — the system is told the trees' positions (grid) and the camera's position (GPS), so it computes geometry, not guesses from pixels. (ML is a later option for health-from-leaf-colour, not now.)

4 · Two capture modules (backups of each other)

MODULE 1 — WEB DRAG-DROP (office)

Bulk ingest

Drop a folder of named photos + a folder of 360s → match preview (matched / unmatched) → resolve misses → Publish. Auto-links + auto-places everything. Use after a trip with a standalone 360 cam.

MODULE 2 — LIVE APP (field)

Ultra-fast "2-sec" capture

Rapid mode in the planter app: live viewfinder, big shutter, GPS auto-stamps, auto-advance to next tree, sticky status, offline queue + batch sync. "Tap, step, tap, step." For a quick per-tree survival pass.
