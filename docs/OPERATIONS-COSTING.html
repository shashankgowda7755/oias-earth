1 · How the operation runs (per city)

STEP 1 — STAND UP

Recruit + train local

4–8 field staff per city via a manpower agency (they live there → no travel). Half-day training: app, GPS lock, framing, the waypoint walk.

STEP 2 — CAPTURE

2-role teams

Tree photographer — 1 GPS photo/tree (~250/day). 360 walker — one sphere every ~100 m: a continuous "click → next point" chain (1 km ≈ 10 points).

STEP 3 — DELIVER

Upload → auto-process → publish

End-of-day upload → auto-ingest + auto-hotspots → quick QA → live. Repeat every 3 months; old cycles kept = the growth timeline.

2 · Capture kit

PER TREE (×100k)

Android + GPS-stamp app

~₹15k phone, dual-band GNSS, EXIF GPS in 2–3 s. The workhorse — 1 photo/tree.

PER PATH (360)

Ricoh Theta X · ~₹38k

Only consumer 360 with built-in GPS + in-camera auto-stitch. One tap = geotagged, finished sphere. One camera, shared.

AERIAL

Drone — optional only

Skip for the core deliverable (DGCA airport-zone permission in all 3 metros). Use only for the top-down "cloud" hero, outsourced per job.

Kit is one-time ~₹50–65k → amortizes to <₹0.30/tree. Irrelevant vs labour.

3 · How we stitch (nothing manual)

  • 360 spheres: Theta-X auto-stitches in-camera → finished equirectangular on capture. No PTGui/Hugin, no laptop.
  • Per-tree photos: exifr reads each photo's GPS → matches it to the nearest tree; sharp compresses to <100 KB.
  • The "pointer" is computed, not clicked: every sphere + every tree know their GPS → hotspot direction = math (bearing + distance). The "→ next waypoint" arrow = bearing to the next sphere. One human action: drag-to-set-north once per sphere.
  • Result: whole-cycle editing ≈ 50 hours, not 250. Re-shoots reuse the GPS → hotspots recompute free.

6 · Before you quote the EXACT number

One thing rules every rupee: real trees-photographed-per-day. Run a 1-day pilot in one dense Chennai plot, count it, and count km of path per site (→ number of 360 spheres). Then ₹/tree is exact, not estimated. Every figure here scales linearly off that single number.

Planning assumptions (validate with the pilot): throughput 250 trees/person/day; loaded labour ₹800 direct / ₹1,200 agency per day; ~3,000 spheres/100k cycle; storage handled separately; platform marginal cost ≈ ₹0 (already built).
